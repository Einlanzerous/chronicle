Signet needs a dry run on rotate. Right now I type `signet rotate` and it just goes, and if I've got the target wrong I find out because something downstream falls over twenty minutes later. I want it to print exactly which secrets it's going to touch, which env files get rewritten, and which containers would get restarted, and then stop. Same predicate as the real run reads, not a separate code path that drifts, because a dry run that checks something different from what the real run does is worse than no dry run at all. Purser has this pattern already I think, or at least the audit command does something close to it.
