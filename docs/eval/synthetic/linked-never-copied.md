The thing I keep coming back to is that the moment you copy a ticket's state into another system you have created a second source of truth and you will not notice when it goes stale. It doesn't announce itself. The card looks right, the status looks right, and it's been wrong for three weeks. So the rule is a reference resolves at render time and never gets written down. And a cache is fine as long as it carries its own age, because a cache with no visible staleness is just a copy that lies. This isn't a feature, it's the thing every feature has to obey.
