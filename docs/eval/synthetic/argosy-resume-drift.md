Okay so the resume position in Argosy is definitely wrong on the tablet and I finally figured out when. If I watch something on the web player and then pick it up on Android it lands a few seconds early, which is fine, whatever, but if I do it the other way round — Android first, then web — it jumps back like a minute and a half every single time. So it's not a rounding thing, it's asymmetric, which makes me think the Android side is reporting the position of the last completed segment rather than where the player actually is. Which would explain the minute and a half, because that's roughly a segment. So somebody needs to go look at what ExoPlayer is actually sending on pause versus what the web player sends, and make them agree on what the number means. It's not a big change but it's been annoying me for weeks.
